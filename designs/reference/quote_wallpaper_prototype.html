Quote Wallpaper – Prototype

Prototype tương tác. Bấm thử các tab, nút Đổi ngẫu nhiên, chế độ template Cố định / Ngẫu nhiên, bật/tắt từng ảnh, câu, template.

Logic random

  • Pool = ảnh đang bật × câu đang bật × template đang bật.
  • Template mode: fixed dùng 1 template; random chọn trong các template đã bật.
  • Không lặp lại liên tiếp: loại item vừa hiển thị khỏi lần chọn kế tiếp.
  • Tự đổi mỗi lần mở app (AppState → active).

Mapping RN

  • Tab bar → expo-router Tabs (5 tab)
  • .wp → <WallpaperCanvas image quote template />
  • .t-* → templates.ts (style object)
  • Lock overlay → chỉ hiện khi preview, không export
  • Lưu ảnh → react-native-view-shot + expo-media-library
  • Chọn ảnh → expo-image-picker
  • State → zustand + AsyncStorage
  • Glass → expo-blur (BlurView)

Giới hạn iOS

App không tự thay wallpaper khi mở khóa máy. Random chạy khi mở app; muốn wallpaper tự đổi cần qua Phím tắt (Shortcuts) với hành động “Đặt hình nền” (mục Cài đặt → Tự động hóa).
