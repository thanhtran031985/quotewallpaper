# Quote Wallpaper

Ứng dụng iOS tạo hình nền từ ảnh, danh ngôn và template. Mỗi lần mở app, hệ thống chọn ngẫu nhiên một ảnh, một câu và một template (hoặc dùng template cố định), cho xem trước trên khung màn hình khóa và lưu vào Ảnh. Có thể xuất nhiều hình vào album để Phím tắt tự đổi hình nền. Expo + React Native + TypeScript, dữ liệu lưu trên máy, không server.

- Bắt đầu: **HUONG-DAN.md**. Hướng dẫn agent: **AGENTS.md**, `.agents/`.
- Đặc tả: `docs/PRD.md`. Thiết kế: mở `designs/reference/prototype.html`.
- Task: `docs/tasks/README.md`, tiến độ `docs/tasks/dashboard.html`.

## Chạy nhanh

```powershell
npm install
npx expo start          # quét QR bằng Expo Go trên iPhone
npm test
```
